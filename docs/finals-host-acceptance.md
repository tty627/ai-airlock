# 决赛 session 宿主验收

本清单验证 [受控补证接口](finals-session.md) 在具体设备和宿主上的实际行为。
开始时所有项均为 **NOT_RUN**；本文件本身、Python 单元测试或历史 rc.7 结果都不能使项目变为 PASS。
每项记录 `PASS / FAIL / NOT_RUN / INCONCLUSIVE`、证据位置与适用范围；失败不隐藏或用旧版本结果替代。

## 冻结记录

| 字段 | 需记录的实际值 |
|---|---|
| 源码与安装 | commit SHA、分支、安装包 SHA-256、安装命令 |
| 硬件 | Core Ultra 具体型号、内存、OS 版本、驱动、实际推理设备 |
| 软件 | Python、OpenVINO、模型名称及 revision、宿主名称和版本 |
| 身份 | 所有者/服务身份、宿主进程身份、原始目录 ACL、连接文件 ACL |
| 输入 | 合成案例版本、任务、预期关键事实、已知敏感标记 |
| 结果 | 原始连续录屏、已去敏调用轨迹、结果稿、评分、失败与人工介入 |

不要在录屏、证据包或命令记录中展示 bearer 凭据。输入用合成材料与合成标记；
公共演示不能把真实客户材料用于原文直传对照。

## 执行清单（18 项）

| ID | 验收动作 | PASS 条件 |
|---|---|---|
| H01 | 从冻结源码/安装包在目标机器安装 | 安装身份与依赖可追踪，完整代码与文档可用 |
| H02 | 用 Core Ultra 上实际选择的设备运行 OpenVINO 路径 | 成功返回对应 inference 元数据，设备与模型实测有记录；lexical 不算模型推理 |
| H03 | 在所选生产力宿主安装主 Skill | 真实发现和调用记录；产品及版本准确，不把 TraeCode 当 TRAEWork |
| H04 | 服务身份读取已授权的原始合成目录并启动 | 服务能访问必要资料；连接文件不含原始路径，仅绑定本案例 |
| H05 | 在宿主实际身份下尝试读取原文 | 宿主开放的文件、搜索和终端读取入口被实际权限拒绝；每个入口有记录 |
| H06 | 检查宿主预读、索引、附件及旧对话 | 当前任务开始前原文未通过这些入口进入模型上下文；无法观察之处写明 |
| H07 | 检查连接文件与客户端调用 | 只有预定身份可读取，模型消息/录屏/日志不含凭据；修改或缺失凭据不能获取证据 |
| H08 | 首轮 begin | 客户端得到固定案例身份与带证据 ID 的净化结果，模型只基于释放内容分析 |
| H09 | 给出真正的证据缺口并 query | 返回首轮未披露且与问题有关的新证据；不能只重复首轮排序冒充补证 |
| H10 | 重试同一问题与 request ID | 不重复消耗补证额度或产生不一致证据；同 ID 改问题被拒绝 |
| H11 | 尝试第三轮补证、过大请求和跨案例操作 | 服务端限制生效，不能绕过总预算、次数或授权材料范围 |
| H12 | 首轮后修改原文，再继续当前会话 | 当前会话仍使用固定净化版本；重载需新会话，旧引用不混入新案例 |
| H13 | 测试敏感请求、恶意材料、正常困难任务及查询秘密猜测 | 阻断/隔离与正常成功数均记录；查询按模式净化、不依赖猜测是否匹配隐藏原文，不污染固定保护集合；不退回原文或其他 backend |
| H14 | 断开服务或使客户端请求失败 | 宿主停止调用并说明失败，不扫描原文、打印连接内容或自行改用云端原文处理 |
| H15 | 输出复盘与客户沟通稿并调用 report，加入合成猜测对照 | 格式、已披露引用成员关系、独立敏感模式检查符合预期；拒绝不存在/其他案例引用，稿件成功/失败不依赖猜测是否匹配隐藏原文 |
| H16 | 独立审阅最终主张与缺证说明 | 逐条判定引用支持关系、根因、建议和不确定性；引用 gate PASS 不代替此项；原文知情的秘密审核留所有者本地，不把匹配结果反馈 Agent |
| H17 | 如主张多 Skill，执行主 Skill 到报告 Skill 的真实协作 | 两个独立 Skill 的发现和调用轨迹可见，下游仅收到净化信息 |
| H18 | 端到端演练与对照 | 记录 10 次主流程真实成功数、所有轮次成本和时间；公开失败，不只选最好一次 |

H05 不通过时只能声明协作式接入，不能声称“宿主无法访问原文”。
H02/H03/H08/H15/H16 尚未全部通过时，不能把 session 作为已完成目标硬件与宿主任务的决赛成果。
H17 未通过时，不把普通 Python 函数调用或两个文件的存在计作多 Skill 协作。
H13/H15 的猜测对照只用所有者安排的合成值，分别记录来源证据发布检查与 Agent 输入检查的差异。
report 通过不保证 Agent 自行猜入的无格式秘密被识别，也不等于已证明抵抗所有推断攻击。
是否纳入正式发布按 [决赛计划](finals-2026-plan.md) 的准入条件决定。
